Política de Privacidad

Tratamiento de Datos GPS

BudgetMap solo accede a tu ubicación cuando el radar está activo. No guardamos un historial de tus movimientos, solo procesamos tu posición actual para mostrarte locales cercanos.

Recolección de Datos

Recopilamos información básica como nombre, correo electrónico y preferencias de consumo para personalizar tu experiencia de ahorro.

Seguridad de la Información

Toda comunicación entre tu navegador y nuestros servidores está protegida mediante protocolos HTTPS y encriptación de extremo a extremo para tus contraseñas.
